ExplodedStack Publisher

ExplodedStack Publisher is a private command-line tool that the channel owner uses to upload ExplodedStack's own finished videos to ExplodedStack's own YouTube channel, Facebook Page and Instagram professional account. It does this through the official YouTube Data API v3 and the Meta Graph API.

  • It is not offered to the public, and it is not a website or an online service.
  • Nobody else can sign in. Only the channel owner signs in, on the owner's own computer, to the owner's own accounts.
  • There is no login on this website. This site is only information.
  • It does not list, edit or delete existing videos or posts, and does not read comments, messages, analytics or audience data. It reads only basic account names and the status of its own uploads (see the Privacy Policy).

Uploads to YouTube are subject to the YouTube Terms of Service. ExplodedStack Publisher uses YouTube API Services.
